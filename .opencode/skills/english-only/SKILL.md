# Communication Requirements

- All output must be in English, including chat responses, explanations, generated content, code comments, documentation, and tool-generated text.
- User input may be in any language, including Portuguese.
- Never respond in Portuguese or generate Portuguese content.
- Preserve the original language of user-provided text only when explicitly required for a translation or quotation; otherwise, communicate in English.
- Keep all reasoning and internal processing in the language required by the system. Never expose internal reasoning.
