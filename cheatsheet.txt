================================================================================
 raylib for VB6 - cheatsheet
================================================================================

Conventions
-----------
- Coordinates are in pixels, Y grows downward (same as raylib).
- Colors are ColorRGBA with Single components in the 0.0 .. 1.0 range.
- Text uses ImageFont (bitmap font). There is no TTF/font loading.
- Everything is drawn between BeginDrawing() and EndDrawing().
- Typical entry point:

    Sub Main()
        Run frmMain, 1280, 768, 60
    End Sub

  Run loads the form, creates the GL context and calls Game_Load, then loops
  Game_Update(dt) / Game_Draw(dt) each frame, and finally Game_Unload.

- Helpers to fill structs in one line:

    Vec  v, x, y
    Rect r, x, y, w, h
    Color c, r, g, b, a

    y As Single
End Type

Type Rectangle
    x As Single
    y As Single
    Width As Single
    Height As Single
End Type

Type ColorRGBA
    R As Single
    G As Single
    B As Single
    A As Single
End Type

Type Texture2D
    Id As Long
    Width As Long
    Height As Long
End Type

Type RenderTexture2D
    Id As Long
    Texture As Texture2D      ' color attachment, use it for drawing
    Depth As Texture2D        ' Depth.Id holds the depth renderbuffer
End Type

Type Image
    Data() As Byte            ' RGBA, 8 bits per channel
    Width As Long
    Height As Long
End Type

Type ImageFont
    Texture As Texture2D
    Glyphs() As GlyphRect
    CharList As String
    Height As Long
End Type

Type GlyphRect
    Left As Single
    Width As Single
End Type

Type TexCoord2D
    u As Single
    v As Single
End Type

Type Camera2D
    Offset As Vector2
    Target As Vector2
    Rot As Single
    Zoom As Single
End Type

Type NPatchInfo
    Source As Rectangle
    Left As Long
    Top As Long
    Right As Long
    Bottom As Long
    Layout As NPatchMode
End Type
